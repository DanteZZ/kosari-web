# kosari-net — сервис онлайн-сессий

Отдельный Node-сервис для кооператива в ремейке. Он отвечает за:
- комнаты с кодом-приглашением;
- необязательный пароль;
- четыре места и лобби с выбором героя и готовностью.

Во время игры сервис пересылает сообщения: кнопки гостей идут хосту, снимки мира от хоста идут гостям. Сам бой считает браузер хоста, это место 0.

## Запуск

```bash
cd server
npm install
npm start          # ws://localhost:5181/net, PORT меняет порт
```

В разработке Vite проксирует `/net` на `localhost:5181` (см. `web/vite.config.js`). Поэтому `npm run dev` в `web` и `npm start` здесь работают вместе без настроек.

## Прод

1. Поднимите сервис на любом хосте с Node 18+ (или в Docker, см. `Dockerfile`).
2. Поставьте его за HTTPS-прокси: сайт открывается по https, а браузер разрешает с такой страницы только `wss://`.
3. Соберите сайт с адресом сервиса:
   ```bash
   VITE_NET_URL=wss://net.example.com/net npm run build
   ```
   Без переменной клиент стучится в `/net` своего же домена.

`GET /` отдаёт `{ ok, rooms }` для проверки живости.

## Протокол

Протокол описан в начале `index.mjs`. Клиентская сторона:
- `web/src/remake/net/Session.js` — соединение и комната;
- `net/NetGame.js` — хост и гость в бою;
- `net/sync.js` — снимки и разницы между ними;
- `ui/Lobby.js` — экраны онлайна.
