# Персонажи для генерации

## Общие правила (как у Поцыка)

Каждый персонаж — **10 частей**, PNG с прозрачным фоном. Я ставлю их как есть: без поворотов, ресайза и зеркалирования. Слои — как у Поцыка.

Имена файлов: `<id>_<номер>_<часть>.png`, например `pistoletov_0002_head.png`.

| Номер | Часть | Размер у Поцыка (ориентир) |
|---|---|---|
| 0000 | `hand_r_bottom` — правое предплечье с кистью | 45×85 |
| 0001 | `hand_r_top` — правое плечо | 55×87 |
| 0002 | `head` — голова | 100×116 |
| 0003 | `body` — торс | 103×172 |
| 0004 | `hand_l_bottom` — левое предплечье с кистью | 41×84 |
| 0005 | `hand_l_top` — левое плечо | 59×98 |
| 0006 | `leg_l_bottom` — левая голень со стопой | 88×141 |
| 0007 | `leg_l_top` — левое бедро | 52×137 |
| 0008 | `leg_r_bottom` — правая голень со стопой | 66×141 |
| 0009 | `leg_r_top` — правое бедро | 82×100 |

- **Лево и право — со стороны самого персонажа.** Если он смотрит вправо, его левая рука на правой стороне картинки.
- Поза для нарезки — стоя, **лицом вправо**, руки вдоль тела. Так же сняты части Поцыка.
- Части с запасом на суставах: верх руки чуть заходит под плечо, бедро — под торс.
- Отдельно, если персонаж с атрибутом: `<id>_item.png` — предмет в руке, ручка внизу слева.
- Кладём в `web/public/remake/assets/<player|enemies>/<id>/parts/`.

Боссов можно делать крупнее Поцыка (×1.2–1.5): Руки базуки, Гигачад, Олег Монгол. Размер беру из картинки как есть, поэтому делай сразу в нужном масштабе.

**Стиль**: узнаваемая карикатура на мем, а не фото лица.
