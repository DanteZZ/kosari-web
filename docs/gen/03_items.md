# Айтемы, снаряды, эффекты, интерфейс

## Общие правила
- PNG с прозрачным фоном, вид сбоку.
- Анимация — отдельные кадры `<имя>_0.png`, `<имя>_1.png`… одинакового размера.
- Размеры ниже — ориентир. Поцык ростом около 420 px, по нему и масштаб.
- Кладём в `web/public/remake/assets/items/`, `projectiles/`, `fx/`, `ui/`.

**Уже есть** (из оригинала и первых карт): косарь и пачки косарей, аптечка-хил, оружие классики (Desert Eagle, дробовик, АК-47, РПГ, граната), ящик с лутом, наковальня, дирижабль, бомба Борща, кастрюля, сковородка, вилки Повара.

## 7. Звук (необязательно, если найдёшь)
Кладём в `sounds/`. Короткие фразы боссов — главное, остальное возьму из открытых паков.

- **Фраза-появление** для каждого босса: 11 шт.
- **Фраза при уроне** и **фраза при поражении**: по 1–2 на босса.
- **Музыка**:
  - по 1 треку на главу (6 шт.);
  - боссовый трек на главу (6 шт.);
  - финальный бит для 1Kla$.
- **Озвучка героев**: удар или «эх», получение урона, победа — по 2–3 на героя.
